About

The story behind {{ app_name }}.

01

Origin

X Persona was created by Mark Krynsky as a feature pulled from the X List Summarizer app to make it publicly accessible.

It was adapted from the original functionality built as a Pinokio script that runs on a local machine — reimagined as a web app anyone can use without any local setup.

02

Built With

This app was created with Claude Code using:

  • Opus 4.6 — for planning and architecture decisions
  • Sonnet 4.6 — for coding and implementation

It was deployed using Railway with a persistent volume for the SQLite database and cookie storage.
